# Pally Font Workshop

A reference-led font workflow for Simplified Chinese, Traditional Chinese and Latin, plus 11 curated font families, 16 actual font files and narrative specimen posters.

[Downloads](https://github.com/4chuanMcChicken/pally-font-workshop/releases/tag/v1.0.0) · [Chinese documentation](../README.md) · [Attribution](../ACKNOWLEDGEMENTS.md)

The collection distinguishes open-base selections, explicit glyph edits and shared geometric transformations. It does not claim every glyph as original, or claim that a single screenshot can reconstruct a whole typeface.

Original inspiration and six retained English scripts: Arlan Marat (@arla6ka), design.how / make-font, MIT, commit 1ce5304466db2ba47a7a7524603e86df77c702bd. Original copyright and license are preserved. Chinese workflow, script routing, coverage checks, native release tooling, portable previews and flat packaging are additions in this project.

Install all four sibling Skills with `python3 scripts/install_skills.py` after cloning. The installer refuses existing names. Read each SKILL.md for capabilities and limitations.

Code: MIT. Font software: each family's original SIL OFL 1.1. Generated art/poster images: CC0 to the extent of rights we can grant. No third-party reference screenshots or extracted unknown-provenance glyphs are distributed. Public Prism and Slowday were rebuilt from licensed open sources.
