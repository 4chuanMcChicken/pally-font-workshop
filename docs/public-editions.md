# 私人试样与公开版本

本仓库按字体家族汇总正式试样，不将单字校准、小字集、底库候选与回归测试重复计作可用字库。

- `Prism / 折光`：从 LXGW Marker Gothic 重新生成全部全角几何处理，包括「葉」。不插入私人版的截图提取字形。
- `Slowday / 慢慢来`：从 Yozai 重建，仅对原生自/由作 -1.5/+1.5 度旋转。不是私人版描摹字形的再发布。
- `Leafline`：保留用户确认的独立矢量重绘与正文字距调整。具体路径源见 font-sources/leafline/outline-design.json。
- 单字「葉」、三字「孤葉」、Core Lab 与不同候选底库测试不作为独立可下载家族发布。
- 原始私人文件不被修改或删除。公开版名称与原项目名映射见根目录表格。

开放的 TTF/OTF 本身可用 FontTools 编辑；本项目不宣称提供不存在的 Glyphs/UFO 设计母版。字体改动来源与范围逐套列出。
