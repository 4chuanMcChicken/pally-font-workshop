# Leafline outline source

outline-design.json stores the independently constructed a/n/h/m/f/t paths (UPM 2000), advance changes and affected glyph list. Font software/outline data: SIL OFL 1.1, see OFL.txt.

Source foundation: Urbanist 1.303, native wght=400. Apply the recorded paths with a Cu2QuPen tolerance of 0.5 font units, update dependent accent components/advances and mark anchors to the new optical centers. The reading edition additionally opens r+a by 46 units and P+a by 7 units, including full-size accented a forms. Keep remaining source glyphs intact. Original font and author credit are retained in the distributed font's SOURCE.json.

No screenshot pixels or extracted reference contours are included. The distributed full TTF is also editable with FontTools; this project does not claim a separate UFO/Glyphs master exists.
