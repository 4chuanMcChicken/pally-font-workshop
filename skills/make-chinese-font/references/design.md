# 中文设计与参考分析

## 英文 skill 的审计结论
原 make-font 的 fit_font.py 只接受 glyf/gvar 可变字体；以 n/H 笔画解算字重，以小写/大写宽度类别混合不同轴实例的 x/y。fontlib.py 依赖 H=700、x-height、n counter 和拉丁 sample lines。中文不适合沿用这些目标或求解器：汉字没有 x-height，许多字通常占同一字框，但内部字面/留白差异很大。它的覆盖检查也不足以证明地区正确或通用汉字覆盖。

沿用其工作流程思想，不复制源码。新增工具自主实现。上下文中的 Pally 经验：原生替代字形可设为默认，但必须一起处理重音字、cmap、布局功能与命名；不能只改演示图片。中文替代需要进一步区分 locl、IVS 和简繁对应关系。

## 参考分析表
每个结论标记“观察/测量/推断”，并注明样本字与置信度。

| 维度 | 看什么 | 不可过度推断 |
|---|---|---|
| 字面 | 墨迹框相对字框、四边留白 | 没有字框/字号不能得到真实 EM 比例 |
| 重心 | 墨色分布和视觉重心 | 墨迹质心不等于光学重心 |
| 中宫 | 横竖交汇和内部空间松紧 | 外框面积不能替代中宫测量 |
| 笔画 | 横竖对比、撇捺、钩、转折、末端 | 单一平均笔画值不能说明风格 |
| 结构 | 独体、左右、上下、包围、复杂字 | Unicode 顺序不是结构类别 |
| 语境 | 16px UI、24px 正文、96px 标题 | 放大好看不能证明小字可读 |
| 标点 | 全角/半角、居中/靠边、括号配对 | 字形位置和禁则换行属于不同层 |
| 配套 | 汉字与 Latin 的视觉大小、数字、行高 | 统一 EM 不意味着视觉大小一致 |

结构试样（人工选择，不用于自动分类）：
- 独体：一人大小中永木口日山水
- 左右：你好明林湖谢微
- 上下：字空草想意蓝
- 包围：回国园问同近
- 密集：赢警器藏繁體鬱
- 混排：Pally 陪你开始第 12 天，完成 80%。
不要用这份很小的清单声称覆盖所有结构或字符标准。

## 三条设计路线

选型起点（具体格式、轴、覆盖以下载文件 inspect 结果为准）：

| 方向 | 官方来源 | 接入状态 |
|---|---|---|
| 圆润、亲切 UI | https://github.com/lxgw/975Yuan | 本优化版已用 26.07.26 的 400W/500W 完整实测；各 30,912 码位 |
| 窄体、现代科技方向 | https://github.com/welai/glow-sans | 已测静态 CFF 与原生 500/600/800；项目已归档，固定 v0.93 |
| 可变黑体 | https://github.com/google/fonts/tree/main/ofl/notosanssc | 已测 glyf VF 的 wght=700 静态试样 |
| 现代黑体 | https://github.com/adobe-fonts/source-han-sans | 候选；需选定地区/格式后实测，不能把 CFF2 直接传给本工具 |
| 阅读宋体 | https://github.com/adobe-fonts/source-han-serif | 候选；需逐版本核查与小样验证 |
| 手写人文 | https://github.com/lxgw/LxgwWenKai | 候选；覆盖和字重不得由家族名称推断 |

同家族升级可能改变字形或覆盖，继续旧项目时优先按 SHA256 找回旧底库。只有显式改版才换用新发布；两字重的地区和来源版本须一致。975 圆体实测来源校验值和本次验证范围见 [validation.md](validation.md)。

1. 原生轴/原生字形：最可靠；轴只改变该底库定义的设计空间，不能生成它没有的结构。第一版自动脚本支持这一条。
2. 选定品牌字逐字设计：v0.3 提供静态 glyf 的模板导出、显式轮廓编辑导入与受影响别名记录，见 [核心字编辑](glyph-editing.md)。使用许可允许的骨架或用户自有字稿；逐字检查内白、交叉、曲线、标点和栅格化。可逐字修改圆角、切角和末端，但没有自动圆角滤镜或从几字自动“补齐”整个字库。
3. 全字库系统改造：需要可靠部件关系、例外表、设计源和跨字重插值兼容性。IDS 只描述抽象结构，不等于实际字形组件坐标。没有这些条件时选择更接近的底库；不要承诺自动重绘几万字。

手写截图只提供少数字样时，可做有限字符字体；补字需要用户稿件、明确允许的开源骨架或专门模型/人工绘制。AI 生成的字形图片不是经过 Unicode 映射和排版验证的字体。

## 地区与排版
确认简中/台繁/港繁；基础 cmap 覆盖不代表地区字形正确。对同一码位观察骨、直、令等地区敏感样字（如语料有）。保留并测试 locl；竖排时保留 vert/vrt2、vhea/vmtx/VORG（存在时）。IVS 的 cmap format 14 是序列映射，不能按单一码位缺字检查。脚本明确拒绝含变体选择符的语料，转入专门检查流程。
