# 字体 Handbook / Preview

## 用户指定的默认结构

1. 顶部以字体本身呈现有性格的大标题，标题就是字体名字。
2. 下方是简短 description，说明这套字体的感觉和用途。
3. 逐个展示真实存在的字重；每个字重有独立字样，便于直接比较。
4. 展示数字、中文标点与符号。

目的来自用户原话：希望看到不同字重以及符号“单独的是什么样子的”。

这是后续字样册的层级与内容要求；参考图中的手写风格属于本次字体方向，不是所有字体的默认外观。颜色和装饰随具体字体方向确定，不自动重复本次灰绿背景。

## 真实展示

- 所有字样使用实际导出的字体文件；每栏名字、数字字重与文件内 OS/2 信息一致。
- 只有 Regular 的字体只展示真实 Regular，不用 CSS 或描边伪造 Bold。若有 Light/Regular/Medium 而无 Bold，按实际三字重命名。
- 中文册以汉字、中文标点和数字为主；拉丁字母仅作兼容或用户要求的补充。
- 字形展示区与装饰分开。手绘下划线等可独立绘制，不把装饰图当作字体字形。
- 字体来源、完整覆盖、已改字形和已知限制放在后面的说明区，不占据主要展示区域。

## 生成器

`scripts/font_book.py` 根据字体包内的 JSON manifest 生成 PDF 与 HTML。先安装 core requirements.txt，再安装 requirements-book.txt。完整配置示例见 [examples/handbook.json](../examples/handbook.json)，使用前将字体路径、字符与说明改成实际项目结果；不能照抄示例中的覆盖或来源。实际字体包中也包含可直接复现的 book-manifest.json。

```sh
python "$SKILL_DIR/scripts/font_book.py" --manifest font-kit/book-manifest.json --out-dir font-kit/handbook
```

首页包含标题、简介、最多三个代表字重和数字符号概览；后续每个字重独立一页，最后展示数字符号与来源说明。超过三个字重时，符号页按三个一组分页。每一栏校验真实字重和字符映射；TTF 嵌入真实字体，CFF 使用原生矢量轮廓绘制并记录模式。

manifest 的字体路径相对 manifest 文件。HTML 默认将 WOFF2 与共同码位集合内嵌，减少用户打开试字的步骤；缺字时保留上一份有效试字并明确提示，避免回退字体造成误判。设 embed_webfonts=false 可改为外部字体路径，路径相对最终交付目录；不使用工作机绝对路径。language 可设 zh-Hans、zh-Hant-TW 或 zh-Hant-HK，切换 HTML 控件文字，不转换用户文案。生成过程先写临时目录，成功后提交完整字样册。

## 验证

生成 PDF 后必须渲染检查首页、至少一个字重页、符号页；检查实际字体、空白字形、边界、文字溢出和分页。生成器的几何检查不能替代这一步。HTML 应实测自定义文字和缺字阻断；浏览器工具不允许 file 协议时可通过本机 HTTP 检查内嵌版本，并如实记录未实测本地文件直开。只声明实际完成的检查。

当前版已实测：乱写 Light 300 / Regular 400 / Medium 500，5 页嵌入 TrueType 的 PDF、三字重 HTML；CFF 单行矢量绘制另作烟雾测试，不由此推断全部 CFF 排版场景已验证。
