# English Font · Pally v0.1

将英文参考转为真实字体。继承 make-font 的开放底库与测量思路，增加参考确认、保守构建、真实字符覆盖与直观下载包。英文与中文分别设计；不把中文底库附带 Latin 当作已经设计好英文。

## 先把参考读对

读取已有对话，只补问影响结果的缺项：标题/正文/UI、喜欢的笔形、语言/必需文字、字重。已有图片就直接使用。用户没有命名时提出名字，不为名字停工。

- 观察具体结构：单/双层 a/g、圆形/椭圆 o、e 开口、t/f 端点、字宽、大小写比例、字距。用途不由参考的排版尺寸自动决定。
- 不把任何截图都硬送入测量器：继承的 measure_image 需要 H 和明确文字，连写、重叠或样本不全会失败。记录无法可靠测得的参数，用同字、同视觉高度的真实字样比较，不能编造 em、字距或完整字母表。
- 图片只提供参考中出现的字母；未出现的大写、数字、重音字必须另排。截图的紧排可以是海报字距，不等于适合正文的字体默认间距。
- 使用允许修改的开源底库；保留其版权和许可。默认不复制/描摹参考轮廓与字距。需要逐字新设计时明确记录实际编辑和来源，不将未知参考混入后声称整套已获商用授权。

## 用可看的结果确认

1. 先把参考和 2–3 个合适候选排在一起，区分底库选型与已完成的设计；给出推荐和关键差异。
2. 用实际 TTF/OTF 展示参考原词、新词、Aa–Zz、数字、符号和一段用途相符的文字。让用户选择真实方向，而不是批准读取/导出这些已授权操作。
3. 用户确认后扩展整套。用户已说直接做/你决定时执行，并随成果列出风格延展与限制；不机械重复确认。

默认保留底库完整覆盖。英文字母、ASCII 可打印字符是最低基准；扩展拉丁、货币和弯引号按实际需要验证。Latin-1 覆盖不等于支持全部欧洲语言；组合重音还需要布局测试。

## 构建

先读 [构建与检查](references/release.md)。Python 3.11+，安装 requirements.txt。

- 默认路线：原生可变轴实例化，或静态底库；保留 cmap、布局、字距与真实字重。scripts/release_font.py 生成字体、WOFF2、实际渲染 PNG、内嵌网页试字、许可和报告。未改轮廓标为选型/实例版，不称原创全套。
- 调参路线：参考确实提供可靠数据、且底库合适时，可用继承的 measure_font.py / make_targets.py / fit_font.py / space_font.py。读 [测量](references/measuring.md)、[拟合](references/fitting.md)、[间距](references/spacing.md)。它们只支持 glyf 可变底库；x/y 混合不是通用设计器。保持 3% 拉伸限制，检查重音组合、mark anchors 和遗漏的 GPOS 类型。可选拟合依赖见 requirements-fit.txt。当前版本实测的是默认路线，不将可选求解器称为已完整验证。
- 不以修改 OS/2 weight 数字、CSS bold、描边或斜切伪造字重/斜体。v0.1 默认发布器只支持 upright 静态 glyf 与 glyf 原生可变实例；CFF/italic 转专项流程。

```sh
python scripts/release_font.py base.ttf --config design.json --license OFL.txt --out kit-v1
```

## 交付

根目录只放可安装 TTF 与一个 `资料/` 文件夹；多字重平铺。资料包含许可、配方、来源 SHA256、覆盖/排版/往返报告、WOFF2、CSS、字样图和 HTML。ZIP 与直接字体链接都提供。不自动安装系统字体。

Handbook 顺序：字体名字作大标题、短介绍、每个真实字重单独字样、完整大小写、数字符号、来源与差异。字样必须使用交付文件。PNG/HTML 不是 PDF；用户要求 PDF 或完整手册时另行制作并渲染查看，不能把尚未生成的 PDF 称为完成。

检查 16/24/48/96 px；细线标题字体不要仅凭放大效果声称适合小字号。网页试字须等待字体加载，缺字应明确提示并保留上一份有效字样，不能用回退字体掩盖。只报告实际运行的检查；FontBakery/OTS、全语言、全部 kerning pair、系统字体菜单未测则不宣称通过。

软件来源见 UPSTREAM.txt；MIT 许可只约束 Skill 代码，不替代字体的 OFL。

本版的实际验证范围与可复现命令见 [验证记录](references/validation.md)。
