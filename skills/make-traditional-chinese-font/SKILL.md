# 繁體中文字体

先读取同包核心 [make-chinese-font](../make-chinese-font/SKILL.md)，遵循参考匹配、构建、视觉验收和交付规范。本入口与核心必须保持同级安装；核心缺失时指出依赖，不能声称能够独立构建。所有命令的 SKILL_DIR 指向核心目录，不是本入口。

分别处理 zh-Hant-TW 与 zh-Hant-HK。不能仅凭繁体字符推断地区；地区未定先做风格试字，正式地区交付前明确地区。当前没有内置台/港标准字表，按明确语料检查，不借简体字表宣称繁体合格。

用户修改目标范围时服从新选择。图片中的繁体不覆盖用户的简体要求，反之亦然。先过少量核心字的视觉关，再扩展；不把底库重命名等同风格定制。最终包保持 TTF/OTF 在根目录、其他文件在资料/。

新项目先遵循核心的需求沟通与小样确认流程，主动邀请 reference；已有明确回答不重问。用户要简繁兼容时由核心统筹同一文件或按地区拆分，不把本入口限制误当字库必须排除另一套字符。
